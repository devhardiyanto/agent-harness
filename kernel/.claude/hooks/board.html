Work Board

Belum ada snapshot. Papan terisi setelah kamu menempelkan keluaran dari repo project.

DATA CONTOH: bukan data project-mu. Tempel snapshot nyata untuk menggantinya.

Tempel snapshot

Diproses di browser ini saja. Snapshot hanya berisi metadata: tanpa judul, teks kriteria, isi bukti, path kode, atau email.

Cara mengambil snapshot

  1. Di folder root project, jalankan perintah ini (Git Bash).
    node .claude/hooks/harness.mjs snapshot --json | clip
  2. Kembali ke halaman ini dan tempel di kotak sebelah.
  3. Ulangi setelah /harness:impact, /harness:plan, atau /harness:approve bila ingin papan mutakhir.

Tanpa browser terpisah: node .claude/hooks/harness.mjs board --open membuat berkas papan lokal berisi snapshot tertanam.
